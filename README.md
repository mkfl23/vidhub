## VidHub 是什么？

VidHub 是一款支持 **macOS / iOS / iPadOS / Apple TV / Android 手机 / Android 平板 / Android 电视**的跨平台视频播放器。

它能连接的视频来源非常全：

- **国内主流网盘直连**：阿里云盘、百度网盘、115 网盘、移动云盘、123云盘等，无需下载，直接在线播放
- **NAS 网络存储**：通过 SMB / WebDAV 协议接入群晖、极空间等 NAS 设备
- **媒体服务器**：支持 Emby、Jellyfin、Plex、fnOS 等主流媒体服务器直连
- **本地文件**：手机、电脑本地视频，当然也支持

格式兼容性也不用担心，MKV、MP4、AVI、RMVB、WMV、MOV、WEBM……基本上你能找到的视频格式，VidHub 都能播，支持 4K、HDR、杜比视界。

## 免费版够用吗？VIP 有啥区别？

VidHub 可以免费下载使用，但免费版有一些限制：**播放 1080P 以上视频** 和**播放非 MP4 格式视频**各只有 5 次的免费试用次数，用完就需要升级 VIP。

VIP 版解除了这些限制，还**去掉广告**。

核心功能——Emby/Jellyfin/Plex 协议连接、SMB/WebDAV 协议连接、多种网盘直连、媒体库视频墙——**免费版全都有**，不锁。

## 激活方式

购买后会收到激活码，激活步骤如下：

1. 在手机上打开 VidHub，进入「设置 > 登录」，注册并登录账号
2. 用另一台设备访问官方兑换页面，页面会显示登录二维码
3. 在 VidHub 应用内点击右上角扫码按钮，扫描二维码并确认登录
4. 在兑换页面粘贴激活码，点击「激活 VidHub 会员」，重启 App 即可

自动发货，支持网页 / 短信 / 邮箱接收激活码。一个账号最多可激活 **5 台设备**，设备迁移时在原设备账号登出即可。
